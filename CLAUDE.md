# Working on this repo

The app is `kittycal/`, a period tracker PWA (Hello Kitty themed). The person
who owns it is not technical: report in plain words, no jargon.

Before designing, building or redesigning anything in Kittycal, read
`kittycal/PRODUCT.md` and answer its gate (section 3) in the PR description.
A feature that cannot name the job it serves, or that repeats something
another screen already answers, is not built. "Tests pass" means correct, not
useful; both are required.

Also in `kittycal/`: `AUDIT.md` (correctness), `COMPETITORS.md` (the field),
`README.md` (how it works, how to test).
